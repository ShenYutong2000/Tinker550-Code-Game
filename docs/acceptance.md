# 完整手工验收清单

自动检查：在仓库根目录运行 `npm ci`、`npm run check`。截图对照资料与原始操作记录见 [基准说明](../baseline/README.md)。

## 呈现

在干净的浏览器站点数据中运行 `npm run dev`，等待字体与最初两条机器人消息加载完毕。浏览器保持默认缩放，依次设置桌面 `1440×900`、平板 `1024×768`、手机 `390×844`，核对侧栏、聊天区、输入框、顶部按钮、手机底部导航与基准截图。Canvas 随机元素、Logo 动画和打字动画按行为核对。

## 首版游戏

1. 将机器人命名为 `Bolt`；输入角色 `a cat`、动作 `catching stars`。标题应自动变为 `Cat: Catching Stars`。
2. 查看自动打开的设计地图与首次引导。两张红色便签分别对应角色和动作；点击确认后转为黄色，`Make my game!` 可用。
3. 生成游戏并选择一项预测，点击 `I think so!`。打开游戏卡片，确认面板标为 `v1`，画布可获得焦点并响应控制键或鼠标。
4. 点击 `Save`，创建新项目后从侧栏加载旧项目；核对名称、对话、便签和 `v1`。关闭并重新打开同一站点，确认项目仍在。

## 第二轮迭代

1. 打开 `v1` 试玩，等待试玩反馈提示，输入 `nothing happened` 等体验描述。
2. 关闭首次迭代引导，在建议卡片中选择一项，完成句子或点击建议选项。确认新红色便签并再次生成。
3. 打开新游戏卡片，确认面板标为 `v2`。点击 `Undo`，核对返回 `v1`，地图和试玩配置同步恢复。

## 导出与预览

在游戏面板点击 `Export HTML`。普通浏览器应出现复制代码弹窗；将代码另存为 HTML 后打开，确认游戏可独立试玩。再运行 `npm run build`，分别检查 `dist/index.html` 可由静态服务器访问、`dist/standalone-preview.html` 可直接双击打开整站。根目录 `index.html` 是源码入口，直接双击应显示预览入口说明。

`file://` 与本地服务器的 `localStorage` 数据互不共用。验收加载时请始终使用同一访问方式；首次呈现对照请使用干净的站点数据。
